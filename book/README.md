# Making Meaning: Persuasion, Brands, and Design

This mini textbook explores how ordinary products, messages, and interfaces acquire meaning. It begins with persuasion, moves through brand archetypes and visual design history, and then uses one plain white T-shirt to show how the same physical object can be presented in radically different ways.

The final chapter connects those ideas to AI-assisted creative and technical work. The goal is not to let a tool make every decision for you. It is to help you define intent, set useful boundaries, inspect the result, and remain responsible for what enters the world.

## How to Use This Guide

Read the chapters in order the first time. Notice how the white T-shirt returns as a shared case study: first as an example of persuasion, then as a carrier of archetypal meaning, then as an object shaped by visual language, and finally as a complete market presentation.

As you read, pause at the questions and compare the examples with designs you encounter. The final chapter turns the framework into a repeatable workflow for specifying, generating, checking, reviewing, and versioning AI-assisted work.
